# aviation-analysis-dashboard
✈️ Aviation Accident Analysis Dashboard
Multi-Decade Risk & Safety Analytics (1948–2022)

📌 Project Overview
This project analyzes over 88,000 aviation accident and incident records spanning more than seven decades (1948–2022).
The objective was to transform raw aviation safety data into a structured, interactive analytical dashboard capable of identifying long-term trends, operational risk concentration, and severity distribution patterns.
The final output is a fully dynamic Excel-based dashboard built using advanced Pivot architecture, structured aggregations, and interactive slicers.

📊 Dataset Summary
•	Total Records: 88,889 aviation events
•	Time Period Covered: 1948 – 2022
•	Total Columns: 31 structured variables
•	Geographic Scope: Multi-country dataset
•	Granularity: Event-level (each row = one aviation event)
Key Variables Used
•	Event Date
•	Investigation Type (Accident / Incident)
•	Aircraft Category
•	Aircraft Damage Classification
•	Purpose of Flight
•	Phase of Flight
•	Weather Condition
•	Injury Severity (Fatal, Serious, Minor, Uninjured)
•	Country / Location

🎯 Business Objectives
This project was built to answer the following analytical questions:
1.	How have aviation accidents evolved over time?
2.	Which phases of flight carry the highest operational risk?
3.	What severity distribution patterns exist across events?
4.	How significant is aircraft damage impact?
5.	What flight purposes are associated with higher exposure?
6.	Can risk be segmented by geography and aircraft type?

🔍 Key Analytical Insights
1️⃣ Long-Term Trend Analysis
•	Peak accident frequency observed in early 1980s (~3,500+ annually)
•	Gradual multi-decade decline afterward
•	Recent years stabilize around 1,500–1,700 annually
This trend reflects improvements in:
•	Aircraft technology
•	Safety regulation
•	Pilot training standards

2️⃣ Risk Concentration by Phase of Flight
Highest event counts:
•	Landing: 15,428
•	Takeoff: 12,493
•	Cruise: 10,269
•	Maneuvering: 8,144
Critical flight transition stages (Takeoff & Landing) show elevated exposure.

3️⃣ Aircraft Damage Severity
•	Substantial Damage: 64,148
•	Destroyed: 18,623
•	Minor Damage: 2,805
Majority of recorded events result in substantial structural impact.

4️⃣ Purpose of Flight Risk
Top category:
•	Personal Flights: 49,448 events
Significantly higher exposure compared to commercial or structured operations.
This may indicate variability in:
•	Training levels
•	Regulatory oversight
•	Operational discipline

🛠 Technical Implementation
This dashboard was built entirely in Microsoft Excel, emphasizing strong analytical fundamentals.
Techniques Used:
•	Advanced Pivot Table architecture
•	Multi-layer aggregation logic
•	KPI modeling (SUM, COUNT, conditional grouping)
•	Interactive slicers:
o	Event Date
o	Country
o	Aircraft Category
o	Purpose of Flight
•	Structured dashboard layout
•	Trend analysis via time-series pivot grouping
•	Data cleaning and normalization
No Power BI or external BI tools were used.
The objective was to demonstrate strong core data modeling capability within Excel.

🖥 Dashboard Features
✔ KPI Cards (Dynamic)
✔ Time-Series Line Chart (Trend by Year)
✔ Aircraft Damage Distribution (Pie Chart)
✔ Risk by Phase of Flight (Treemap)
✔ Top 10 Purpose of Flight (Bar Chart)
✔ Geographic Filtering via Country Slicer
✔ Aircraft Category Filtering
All visuals are dynamically linked to pivot tables.
